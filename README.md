# Lampiangram 🌵📸

Projeto escolar desenvolvido para apresentar a história de Lampião em formato de rede social fictícia.

A proposta foi imaginar como seria um perfil inspirado no Instagram para Virgulino Ferreira da Silva, conhecido como Lampião, usando uma linguagem visual mais próxima dos estudantes, mas mantendo o conteúdo baseado em informações históricas.

---

## Sobre o projeto

O **Lampiangram** é uma página web criada com finalidade educativa.

A ideia foi transformar um conteúdo histórico em uma apresentação visual e criativa, usando o formato de rede social apenas como recurso de linguagem.

Apesar do visual descontraído, o conteúdo apresentado no projeto trata de fatos reais ligados a Lampião, Maria Bonita, ao cangaço e à violência praticada pelo bando.

O projeto mistura:

- história;
- pesquisa escolar;
- linguagem de rede social;
- design simples;
- apresentação educativa;
- criatividade na forma de apresentar o conteúdo.

---

## Objetivo

O objetivo do projeto foi apoiar um trabalho escolar, apresentando informações sobre Lampião e o cangaço de uma forma diferente da apresentação tradicional.

Em vez de apenas montar um cartaz ou slide, a ideia foi criar uma experiência visual parecida com um perfil de rede social, tornando o conteúdo mais interessante para a apresentação, sem transformar Lampião em herói ou personagem romantizado.

## Importante

Este projeto é uma **releitura visual educativa baseada em fatos históricos**.

O formato de rede social foi usado apenas como recurso criativo para apresentar o conteúdo de maneira mais próxima da linguagem dos estudantes.

O projeto não tem a intenção de homenagear, romantizar ou defender Lampião e o cangaço. Pelo contrário: apresenta um recorte histórico sobre uma figura marcada por violência, medo e crimes reais.

Para pesquisas mais aprofundadas, é importante consultar livros, materiais didáticos e fontes históricas confiáveis.
